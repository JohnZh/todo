# Todo

A single list of things someone needs to do, kept on their own machine and worked through in the browser.

## Language

### Things

**Todo**:
One thing that needs doing. Each Todo has an id that names it for its whole life and is never given to another Todo, not even after the first one is deleted.
_Avoid_: Task, item, entry

**Title**:
The text of a Todo. It is never blank and never starts or ends with whitespace, wherever the Todo came from.
_Avoid_: Name, text, description

### States

**Active**:
A Todo that still needs doing. Every Todo is either Active or Done, never anything else.
_Avoid_: Pending, open, incomplete, todo (as an adjective)

**Done**:
A Todo that no longer needs doing.
_Avoid_: Completed, finished, closed

### Actions

**Add**:
Put a new Todo on the list. A new Todo starts Active.
_Avoid_: Create, new

**Rename**:
Give a Todo a different Title.
_Avoid_: Edit, update

**Toggle**:
Flip a Todo between Active and Done.
_Avoid_: Complete, check, mark

**Delete**:
Take a Todo off the list for good. There is no archive or trash to bring it back from.
_Avoid_: Remove, archive

### Views

**Filter**:
Which Todos are shown: every Todo, only the Active ones, or only the Done ones. A Filter only changes what is shown, never any Todo.
_Avoid_: View, tab

**Sort**:
The order Todos are shown in: the order they were Added, by Title alphabetically ignoring case, or Active before Done. Todos that tie stay in the order they were Added.
_Avoid_: Order by, ranking

**Stats**:
How many Todos there are in total, how many are Active and how many are Done, counted over every Todo whatever the Filter.
_Avoid_: Counts, summary
